# THE CASA BASICS

**A Full-Stack E-Commerce Website for Kitchen and Home Essentials**

## About the Project

THE CASA BASICS is a full-stack e-commerce web application designed to provide customers with an easy and convenient online shopping experience for kitchen and home essentials.

The project includes a responsive frontend, backend APIs, user authentication, product management, shopping cart, wishlist and order management.

## Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- CSS
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- REST APIs
- JWT Authentication

## Main Features

- Responsive homepage and product catalog
- Product search and browsing
- User registration and login
- Shopping cart management
- Wishlist functionality
- Product details
- Checkout process
- Order placement
- Order tracking
- User profile management
- MongoDB database integration

## How to Run the Project Locally

### 1. Clone the Repository

```bash
git clone https://github.com/snehagoyal10244/the-casa-basicss.git
```

### 2. Run the Frontend

```bash
cd Frontent
npm install
npm run dev
```

Open the local URL displayed in your terminal.

### 3. Run the Backend

Open another terminal:

```bash
cd backened
npm install
```

Configure your environment variables in a `.env` file using the variable names required by the backend configuration. Add your MongoDB connection string and required authentication secrets.

Start the backend using the development script configured in `package.json`:

```bash
npm run dev
```

If no development script is configured, use the server start command specified by the project.

The backend runs locally on port 5000 when configured with the default project settings.

## Database

MongoDB Atlas is used for database management and storing application data such as user accounts and orders.
